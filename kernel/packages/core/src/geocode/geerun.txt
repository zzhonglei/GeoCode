Run a Python script that uses Google Earth Engine, within a task, and return its output.

The script runs in the session's directory, in GeoCode's built-in Python with the common packages for geospatial work. `ee` is already initialized for the user's project: do not call ee.Authenticate() or ee.Initialize(). Nothing can be installed into this Python; if an import fails, do that part outside geerun.

Each piece of work the user asks for, such as the NDVI of a study area or a land-cover map, is one task: create it with "new_task", then run every later script of that work with "task". A task keeps the assets its scripts save, for later steps and later conversations; a script can also load another task's assets with gee.load("other-task-id/name").

Split complex work into several scripts in the same task, each saving its checked result with gee.save for the next to load, so a failing step is fixed and rerun alone. Download an image the user wants with gee.download; export to Google Drive with gee.to_drive only when the user asks for it. Do not delete tasks or assets unless the user asks.

Use these functions of GeoCode's package geocodekit.gee (import geocodekit.gee as gee) for these steps instead of writing your own:

  gee.region(path: str, layer: str | None = None) -> ee.Geometry
    Reads the study region, the one polygon feature of a local vector file, in the file's coordinate system.

  gee.images(collection: str | ee.ImageCollection, region: ee.Geometry, start: str, end: str, **masking) -> ee.ImageCollection
    Finds the dataset's images over the region from start to end, printing for each acquisition the share of the region it covers and how much of that is cloud-free. Clouds are not masked yet; gee.composite masks them.

  gee.composite(images: ee.ImageCollection, region: ee.Geometry, dates: str | list[str] | None = None, method: str | None = None, mask: bool = True, min_coverage: float = 0.999) -> ee.Image
    Composites the images with clouds masked, the clearest first; stops when holes leave less than 99.9% of the region covered, saying where they are and how to fill them.

  gee.save(data: ee.Image | ee.FeatureCollection, name: str, *, title: str, description: str, crs: str | None = None, crs_transform: list[float] | None = None, shape: tuple[int, int] | None = None, scale: float | None = None, bands: list[str] | None = None) -> ee.Image | ee.FeatureCollection
    Saves to the task and reads it back, reusing the same content saved before. Write title and description in the user's language.

  gee.load(name: str) -> ee.Image | ee.ImageCollection | ee.FeatureCollection
    Reads an asset of this task, "other-task-id/name" of another, or "projects/..." by its full path.

  gee.download(image: ee.Image, path: str, *, crs: str | None = None, crs_transform: list[float] | None = None, shape: tuple[int, int] | None = None, scale: float | None = None, resampling: str = "near", dtype: str | None = None, scale_offset: bool = False, bands: list[str] | None = None) -> str
    Downloads the image to a GeoTIFF in the session's directory and returns the path it saved to.

  gee.to_drive(image: ee.Image, name: str, folder: str = "GeoCode", *, crs: str | None = None, crs_transform: list[float] | None = None, shape: tuple[int, int] | None = None, scale: float | None = None, resampling: str = "near", dtype: str | None = None, scale_offset: bool = False, bands: list[str] | None = None) -> None
    Exports the image to a folder of the user's Google Drive, waiting until it is done.

Example:
    import geocodekit.gee as gee

    region = gee.region("data/taipei.shp")
    images = gee.images("COPERNICUS/S2_SR_HARMONIZED", region, "2024-06-01", "2024-09-01")
    composite = gee.composite(images, region)
    # A composite has no bounds: clip it before gee.save, gee.download or gee.to_drive.
    composite = composite.clip(region)
    gee.download(composite.select(["B4", "B3", "B2"]), "output/taipei_rgb.tif")
