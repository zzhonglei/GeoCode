Read the documentation of QGIS Processing algorithms.

Actions:
- groups: list the algorithm groups, each with how many algorithms it holds.
- algorithms: list the algorithms in one group, each with its ID, name and a one-line summary.
- help: read one algorithm's documentation: every parameter with its type, default and acceptable values, and the outputs.
- search: find algorithms by English keywords, best matches first (at most 10, with the total count). Use it when you do not know an algorithm's ID.

If an algorithm's documentation leaves something unclear, read the official QGIS page linked at its end with webfetch.
