Use this tool to perform operations on the user's Google Earth Engine (GEE) workspace via Python scripts.

Two execution modes (provide exactly one):
- script: Inline Python code string. Use for quick queries (image band info, collection size, date range) and simple computations.
- script_path: Absolute path to a .py file. Use for multi-step pipelines, scripts that need iterative debugging, or scripts worth preserving for the user.

IMPORTANT:
- Always prefer functions from the built-in "geocode" module over writing equivalent logic manually. They handle authentication, progress reporting, error handling, and idle-timeout prevention automatically.
- Wrap ALL long-running operations with heartbeat() (.getInfo(), reduceRegion(), classify(), export, etc.). The 60s idle timeout will FORCE-KILL the script without it.
- Use print() frequently throughout the script to surface progress and intermediate state.
- When an AOI is needed, you MUST use load_region() with a local vector file rather than GEE built-in boundaries (FAO/GAUL, USDOS/LSIB) — local files give the user accurate, controlled boundaries.

Built-in module "geocode":
  This tool's built-in helper toolkit, pre-injected into every GEE script. No installation needed. Import at the top:

    from geocode import init_gee, load_region, check_coverage, heartbeat, download_image, export_image

  Functions:

  - init_gee(project_id: str = None) -> None
    Initialize GEE. Call at the top of every script.
    The project ID is read automatically from GeoCode config — do NOT pass project_id unless the user explicitly asks to override the configured one.

  - load_region(file_path: str) -> ee.FeatureCollection
    Load a local vector file (.shp, .geojson) containing exactly ONE feature as an ee.FeatureCollection.
    Call .geometry() on the result to get the boundary for filterBounds/clip.
    Never `print(region)` or `region.getInfo()` — coordinate dumps flood the output. Use `.bounds().getInfo()` or `.area().getInfo()` for sanity checks.

  - check_coverage(image: ee.Image, roi: ee.Geometry, band: str = None, scale: int = 30) -> float
    Detect gaps in raster coverage — your substitute for visual inspection. Useful any time you need to verify an image actually covers the AOI (e.g. after cloud masking, scene stitching, other masking, or quality filtering).
      coverage = check_coverage(composite, roi)
    Returns the valid-pixel ratio (0-1). The acceptable threshold depends on your task.

  - heartbeat(message: str)
    Serves two roles during long-running operations: keeps the GEE script alive (avoid idle-timeout kill) and shows the user what's currently happening. Wrap ALL slow GEE server-side calls (.getInfo(), reduceRegion(), classify(), export, etc.):
      with heartbeat("Computing zonal statistics"):
          stats = image.reduceRegion(...).getInfo()

  - download_image(image: ee.Image, filename: str, region: ee.Geometry, scale: int = 10, crs: str = "EPSG:4326", dtype: str = None) -> str
    Download an ee.Image to a local GeoTIFF file. Preferred over export_image for most use cases.
    dtype sets the output data type (e.g. "float32", "int16"); None lets GEE choose.

  - export_image(image: ee.Image, description: str, region: ee.Geometry, folder: str = "GEE_Exports", scale: int = 10) -> dict
    Export an ee.Image to Google Drive. Use for very large images that exceed direct download limits.
    Note: the user MUST manually download the file from Google Drive after export.
