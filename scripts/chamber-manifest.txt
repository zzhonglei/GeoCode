# The desktop closure: what gets vendored from openchamber/openchamber.
#
# One path per line, relative to the upstream root. A directory is taken whole,
# a file alone, and `#` starts a comment. A leading `!` declares an upstream
# entry deliberately left out; vendor.sh reports any entry that is neither.
#
# Editing a line is a structural change: the next merge reads a removed line as
# "upstream deleted these files" and an added one as "upstream added them", and
# neither produces a conflict.
#
# Every package is taken whole. What is left out is upstream's development
# apparatus and anything our own kernel would read; nothing that installs,
# builds or runs.

# --- Read by our own kernel as instructions, skills and project config whenever
# its working directory is inside desktop/. CLAUDE.md and .claude/skills are
# symlinks onto AGENTS.md and .agents/skills. ---

!CLAUDE.md

!.claude
!.opencode
