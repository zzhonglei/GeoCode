# The kernel closure: what gets vendored from the opencode upstream.
#
# One path per line, relative to the upstream repository root. A directory is
# taken whole, a file is taken alone, and `#` starts a comment.
#
# THIS FILE IS THE CLOSURE. Before it existed the selection lived only in the
# session that performed it once, on 2026-07-23, and nothing afterwards could
# check it — which is why two of kernel-upstream's three commits are fixes to
# that selection (a file swallowed by an upstream .gitignore, and one nobody
# noticed was read at import time).
#
# Editing a line here is a structural change, not a preference: the next merge
# reads a removed line as "upstream deleted these files" and an added one as
# "upstream added them", and neither produces a conflict. Both are silent.
# See docs/KERNEL.md §4.4.
